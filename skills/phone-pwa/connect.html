Connect this browser

This grants full access to your Ouroboros, including its controls. Only use a QR created on your own PC.

Open OuroborosThe same link can connect multiple browsers and the installed app during ten minutes. Your connected session lasts up to thirty days, or until you revoke it on the PC. If the installed app has separate storage, use the same link while its window is open; after expiry, get a new QR from the PC.

Add to your Home Screen

  1. iPhone · iOS 26: open this HTTPS address in Safari (not an in-app browser). In the compact layout, tap More (…) → Share. In the Top/Bottom layout, tap Share directly.
  2. Scroll to Add to Home Screen. If missing: Edit Actions → Add to Home Screen. Turn on Open as Web App, then tap Add.
  3. Older iPhone (iOS 18): Safari → Share → Add to Home Screen → Add; there may be no Open as Web App switch.
  4. Android · Chrome: open this address, then ⋮ → Install and create shortcut → Install (some Chrome versions use Add to home screen → Install or Install app). If Chrome offers only Create shortcut, it is a browser shortcut, not proof of an installed standalone app.

Connect first, then install. Launch the icon once while near the PC. Browser and home-screen storage may be separate. The same link authorizes both during its ten-minute window.

When you come back

The PC and tunnel must stay on. There is no offline copy of your chat. If the address changed, open the new PC QR and add the new address to your Home Screen; the old icon cannot find it automatically.
