# Каталог раскладок и формат спецификации

Спецификация деки - JSON. Пример на 24 слайда со всеми раскладками: `assets/example_spec.json`. Собирается командой `scripts/build_deck.py spec.json --render --pdf "Name v1.pdf"` (через `skill_exec`, см. SKILL.md); файлы появляются в новой папке задания.

## Корень

```json
{
  "brand": "Стратегия технологий",
  "meta": "Стратегия · 2026",
  "doc_title": "Название для метаданных",
  "slides": [ ... ]
}
```

- `brand` - метка слева сверху каждого слайда: имя презентации, программы или проекта до 32 знаков. Не имя автора, не название шаблона. Без поля сборщик подставит `doc_title`
- `meta` - метка справа сверху на фотослайдах (титул, разделы, прогноз, финал). На остальных там автоматически `NN / NN`

## Общие поля слайда

| Поле | Назначение |
|---|---|
| `type` | раскладка из каталога ниже |
| `eyebrow` | жанр слайда прописными: «Данные · 2026», «Принципы», «Раздел 02 · Экономика». Обязателен везде, где есть заголовок |
| `eyebrow2` | второй сегмент eyebrow через линию (только титул) |
| `title` | заголовок-утверждение. `\n` переносит строку, `[[текст]]` красит бронзой |
| `sub` | подзаголовок в одну-две строки |
| `foot` | подпись в футере слева: источник, уточнение, масштаб |
| `pill` | медная капсула в футере слева (дата на титуле). Одна на слайд |
| `meta` | переопределить метку справа сверху |
| `day` | `true` - дневной вариант |
| `photo`, `focus` | снимок фона и его кадрирование `"50% 30%"` |
| `nofooter`, `nofootline` | убрать футер / линию над футером |

Текст: строки проходят проверку гигиены. Длинное и среднее тире, восклицательные знаки, латинское `AI`, эмодзи останавливают сборку.

## Раскладки

### Обложки и разделы

`title` - титул с подзаголовком. Фото на весь слайд, eyebrow + `eyebrow2`, заголовок 132px бронзой на 300px сверху, `sub` до 1000px шириной. Футер: `pill` дата, `foot` город.

`title-short` - титул без подзаголовка, заголовок 150px прижат к низу. Для коротких названий из двух-четырёх слов.

`section` - открытие раздела: `number` в большом визире, заголовок 132px, `sub` в одну строку. `"align": "right"` выравнивает вправо без номера (слайд проекта).

`thanks` - финал: заголовок 150px бронзой внизу, `contacts: ["team@...", "Telegram · @..."]` капсулами на фото, номер справа. Футер не рисуется.

### Пункты и принципы

`cards` - 2, 3 или 4 карточки в ряд. `items: [{kind, title, text, photo, pill}]`, `kind` из `ink | glass | caramel | photo`. Три карточки: 568 на 600. Четыре: 420 на 560 с уменьшенной типографикой. Нумерация визиром автоматически (`"numbered": false` отключает, `pill` на элементе заменяет номер). Комбинации: три photo (принципы), ink-ink-caramel (один акцент), четыре glass (равные пункты), glass-glass-ink в дневном варианте.

`stairs` - четыре ступенчатые карточки 420 на 470: нечётные подняты, чётные опущены. Поверхности по умолчанию ink, glass, caramel, photo (четвёртая требует `photo`). `items: [{pill, title, text, kind, photo}]`.

`statement` - тезис слева (60px при фото, 72px без), вертикальный снимок 400 на 880 в центре (`photo`), два пункта с визиром под тезисом и справа. Без `photo` пункты (2-3) выстраиваются в ряд под заголовком на 620px. `items: [{title, text}]`.

`five` - пять вертикальных кадров 460px высотой с номером внизу и подписью под кадром. `items: [{photo, title, text}]`. Для структуры подразделения, направлений, продуктов.

`quote` - крупная цитата или единственный тезис Unbounded 56px, `text`, `author` капсулой, опционально `photo` фоном с плотным scrim.

### Данные

`kpi` - три равные glass-карточки: `items: [{pill, meta, num, label, delta}]`. Число 104px (84px, если длиннее 7 знаков). `delta` - строка («+4,1 млн за год»: знак определяет стрелку) или объект `{text, dir: up|down|flat}`.

`year-kpi` - photo-карточка года слева (`lead: {photo, pill, title, text}`) и 2-3 glass-карточки с полосой: `items: [{meta, num, label, bar (0-100), delta}]`.

`timeline` - 3-4 колонки через вертикальные линии: `items: [{pill, num, label, photo}]`. Последняя капсула медная (`"accent_last": false` отключает, `accent: true` на элементе переносит).

`forecast` - фото фоном, 3-4 колонки лестницей слева направо: `items: [{pill, label, metrics: [{num, label, copper}]}]`. `copper: true` красит число медью (целевой ориентир, маржа). Последняя колонка с медной капсулой.

`model` - вертикальная photo-карточка 560 на 860 слева (`photo`, `card_pill`, `card_title`) и 2-4 строки больших чисел справа `rows: [{num, label}]`. Юнит-экономика, бизнес-модель.

`market` - вложенные уровни TAM / SAM / SOM на фото: `photo`, `levels: [{meta, num, label}]` от внешнего к внутреннему (3 уровня). Любая тройка «весь рынок, доступный, достижимый».

`pictogram` - две стат-карточки слева (`cards: [{pill, num, label, photo}]`, вторая с фото), справа заголовок-число (`num`, `sub`) и сетка силуэтов: `percent`, `total` (по умолчанию 50 = 2% на силуэт). Укажи цену силуэта в `foot`.

`ring-bars` - кольцо с процентом (`ring: {value, label, text}`) и ink-карточка с 2-4 полосами `bars: [{label, value, text, tone}]`. Тона по порядку: бронза, латте, графит. `ring: null` растягивает полосы на всю ширину.

`curve` - качественный график двух кривых (рост с ускорением и отстающая пунктирная): `y_label`, `x_label`, `notes: [{pos: left|peak|right, pill, text}]`. Оси без чисел, в `foot` указать, что кривые иллюстрируют связь, а не замер.

`table` - таблица на 3-6 строк без тяжёлой рамки: `columns`, `rows` (массив массивов), `widths` (`["2fr","1fr",...]`), `highlight_col` красит столбец медью. Первый столбец слоновая кость 500.

### Схемы

Схемы собираются из тех же токенов: узлы glass / ink / caramel, соединители латте 1px, один медный акцент, подписи Inter. Фигуры и линии - SVG, каждая подпись - отдельный HTML-элемент, поэтому в PPTX текст схем редактируется. `accent: true` на элементе делает узел карамельным (один на слайд). Все схемы начинаются со стандартного заголовка (`eyebrow`, `title`, `sub`) и занимают полосу 400-1000px.

`flow` - процесс из 3-6 шагов слева направо: рельс с точками и шевронами сверху, под ним карточки шагов с визиром или капсулой. `items: [{title, text, pill, kind, accent}]`, `accent_last: true` красит последнюю точку медью, `anim: true` пускает по рельсу живую линию.

`layers` - слоёная архитектура: 3-5 горизонтальных полос, слева название слоя и пояснение, справа чипы элементов. `layers: [{title, text, items: [str], kind, accent}]`; `side: {label, title, text}` добавляет вертикальную ink-карточку сквозного слоя справа (безопасность, управление). До 6 чипов в слое, чип до 28 знаков.

`cycle` - замкнутый контур из 3-6 узлов на кольце: точки на эллипсе, шевроны по ходу, подписи снаружи, в центре число или тезис. `items: [{title, text, accent}]`, `center: {num, title, text}`, `anim: true` пускает по кольцу живую линию. Первый узел сверху, далее по часовой.

`matrix` - матрица 2x2 с осями: `x_axis: {label, low, high}`, `y_axis: {label, low, high}`, `quadrants: [{title, text, kind, accent}]` ровно четыре в порядке: слева сверху, справа сверху, слева снизу, справа снизу. `points: [{x, y, label}]` ставит медные точки (координаты 0-100 от левого нижнего угла).

`tree` - иерархия в два уровня с листьями: `root: {title, text}` ink-карточка сверху, `children: [{title, text, items: [str], kind, accent}]` 2-5 ветвей, под каждой чипы листьев (до 6). Оргструктура, портфель, декомпозиция.

`compare` - две колонки «было / станет» или «мы / рынок»: `left: {pill, title}`, `right: {pill, title}`, `rows: [{left, right}]` 2-6 строк, между строками стрелки. Правая колонка по умолчанию карамельная (`right_kind: ink|glass` меняет), левая ink (`left_kind`).

`funnel` - воронка из 3-5 ступеней сверху вниз, справа число и пояснение на каждую: `stages: [{label, num, text, accent}]`. Последняя ступень обычно `accent: true`.

`loop` - два связанных контура, восьмёрка (разработка и сопровождение, стратегия и исполнение): `left: {title, top, bottom, caption}`, `right: {title, top, bottom, caption}` - заголовок в центре петли, метки сверху и снизу внутри петли, утверждение под петлёй; `center_top: {title, text}` и `center_bottom: {title, text}` - заметки у перекрестья. Живая линия включена по умолчанию (`anim: false` даёт тихий контур). Заголовок слайда не длиннее двух строк.

### Живая линия

`anim: true` (у `loop` по умолчанию) добавляет процедурную световую линию: пылевая лента из трёх прядей размечает путь, по нему бежит яркая голова с бронзовым шлейфом. В PDF и HTML попадает один кадр (голова у перекрестья или на середине пути), в PPTX - анимированный GIF, который PowerPoint проигрывает в режиме показа без настройки. Правила:
- только на ночных слайдах; на дневном сборщик предупредит и нарисует без линии
- не больше двух анимированных слайдов на деку: каждый GIF весит 3-6 МБ
- текст схемы лежит над линией, карточки под неё не ставятся; поэтому линия есть только у `loop`, `flow` и `cycle`
- кадры генерирует `scripts/particle_path.py`, результат кэшируется в папке состояния скилла (`cache/anim/`); GIF собирается при `--pptx` или `--gif`, в HTML он вшивается только с `--gif`

### Образ и команда

`team` - утверждение о команде 66px с бронзовой вставкой и пять кадров разной высоты у нижнего края: `photos` (ровно 5), в центральном кадре логотип. Ставь `"nofootline": true`.

`banner` - широкий фото-баннер 1776 на 500 с миссией (`banner_eyebrow`, `banner_text`) и большой бронзовый заголовок под ним (`eyebrow`, `title`). Знакомство, приветствие.

## Как выбирать раскладку

| Содержание | Раскладка |
|---|---|
| Начало, конец | `title` или `title-short`, `thanks` |
| Новая глава | `section` с номером, одна на главу |
| 2-4 равных тезиса | `cards` (glass или photo) |
| 2 факта и 1 вывод | `cards` ink-ink-caramel |
| Один тезис с 2-3 следствиями | `statement` |
| 3 показателя одного уровня | `kpi` |
| Итоги года с динамикой | `year-kpi` |
| Этапы, годы, дорожная карта | `timeline`, `forecast` |
| Процесс со стрелками, конвейер, путь изменения | `flow` |
| Архитектура, стек, уровни платформы | `layers` |
| Цикл, петля обратной связи, замкнутый процесс | `cycle` |
| Два критерия и четыре режима, приоритизация | `matrix` |
| Оргструктура, портфель, декомпозиция цели | `tree` |
| Было и станет, мы и рынок, две модели | `compare` |
| Сужение от входа к результату, отбор | `funnel` |
| Два связанных контура, непрерывность | `loop` |
| Доля чего-либо | `pictogram` или `ring-bars` |
| Экономика, юнит-метрики | `model`, `market` |
| Сравнение вариантов, уровней | `table` |
| Качественная зависимость | `curve` |
| Люди, миссия, цитата | `team`, `banner`, `quote` |

Одна мысль на слайд. Заголовок - утверждение, которое можно прочитать вслух вместо слайда. Если тезис не умещается в одну раскладку, это два слайда.
