# Шрифты для PPTX · Fonts for the PPTX

Статические начертания, собранные из вариативных Inter и Unbounded (лицензия SIL Open Font License 1.1, тексты лицензий лежат рядом: `LICENSE-Inter.txt`, `LICENSE-Unbounded.txt`). Установите все шесть файлов на машину, где открывают PPTX из этого скилла: иначе PowerPoint подставит системный шрифт и переносы строк сдвинутся. Текст в PPTX редактируется и без них.

| Файл | Имя семейства в PPTX | Где используется |
|---|---|---|
| Inter-Light.ttf | Inter Light | описания, подзаголовки |
| Inter-Regular.ttf | Inter | основной текст |
| Inter-Medium.ttf | Inter Medium | капсулы, eyebrow, метки |
| Inter-SemiBold.ttf | Inter SemiBold | заголовки пунктов, таблица |
| Unbounded-Medium.ttf | Unbounded Medium | номера в визире |
| Unbounded-SemiBold.ttf | Unbounded SemiBold | заголовки, крупные числа |

Windows: выделить файлы, правая кнопка, «Установить для всех пользователей». macOS: открыть в «Шрифты» и нажать «Установить». После установки перезапустить PowerPoint.

Install all six files on the computer that opens the PPTX, then restart PowerPoint; without them the text stays editable but PowerPoint substitutes fonts and line breaks move.
